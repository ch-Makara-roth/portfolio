# Product Overview

This is a personal portfolio website for Chhuon Makara Roth, a full-stack developer. The site showcases projects, provides contact information, and includes a blog section.

## Key Features

- SEO-optimized with server-side rendering, comprehensive metadata, Open Graph/Twitter Cards, and structured data (JSON-LD)
- Performance-focused with image optimization, font optimization, lazy loading, and Core Web Vitals compliance
- Responsive design with mobile-first approach and accessibility support
- Interactive UI with smooth animations using Framer Motion
- Contact form with validation using React Hook Form and Zod
- Project showcase with filtering capabilities
- Blog/posts section with markdown rendering

## Target Audience

Potential employers, clients, and collaborators looking to learn about the developer's skills, experience, and work.

## Design Philosophy

Modern, clean, and professional aesthetic with a dark theme. Emphasis on performance, accessibility, and user experience. The site uses a dock-style navigation inspired by macOS.
